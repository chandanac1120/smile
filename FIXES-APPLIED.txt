HOW TO APPLY
------------
1. Keep a backup of your current project folder.
2. Extract this ZIP.
3. Copy the files from the extracted "SMILE CABS" folder over your existing
   project files. Do not delete your existing .git folder.
4. Open index.html with Live Server and test Index, Contact, About, Services,
   Areas and Rentals on desktop and mobile.
5. Commit and push the updated files to GitHub Pages.

The .git folder is not included in this ZIP so the download is smaller.
